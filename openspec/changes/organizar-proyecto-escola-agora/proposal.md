# Organizar el trabajo de Escola Ágora 2026-2027

## Why
Mayka necesita reunir el trabajo escolar en un proyecto independiente y acceder a las actividades publicadas desde el móvil en el colegio.

## What Changes
- Crear el proyecto Escola Ágora Trabalho 2026-2027 en Development.
- Trasladar íntegramente ingles-to-be, incluidos editables, configuración Netlify y evidencias.
- Trasladar las tres propuestas OpenSpec asociadas y conservar referencias desde el proyecto anterior.
- Inicializar OpenSpec para Codex y documentar el acceso móvil.

## Capabilities
### New Capabilities
- `organizacion-escolar`: estructura independiente y localización de materiales escolares.

## Impact
Solo organización local. La URL publicada y el contenido web permanecen iguales. La carpeta local no proporciona por sí sola edición remota desde el móvil. Otros proyectos escolares quedan fuera de este traslado.
